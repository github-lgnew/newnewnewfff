# 旅行记账 · 预算规划应用

一个集成了记账、旅游规划和记事本功能的移动端Web应用。

## 功能特性

### ✅ 已实现功能

1. **记账功能**
   - 记录收入/支出
   - 分类管理（餐饮、购物、交通等）
   - 按类型筛选查看
   - 余额自动计算

2. **存款管理**
   - 显示当前余额
   - 手动修改余额

3. **旅游规划**
   - 获取用户当前位置（GPS定位）
   - 中国主要旅游城市和景点展示
   - 三种旅行模式：
     - **穷游**：最低价格方案
     - **普通游**：性价比方案
     - **高端游**：舒适豪华方案
   - 自动计算从当前位置到目的地的费用（路费+住宿+餐食）
   - 根据当前余额高亮显示可支付/不可支付的景点

4. **记事本**
   - 创建、编辑笔记
   - 自动保存到本地

5. **数据管理**
   - 本地存储（localStorage）
   - 数据导出/导入
   - 数据清空功能

## 使用方法

### 1. 打开应用

直接用浏览器打开 `index.html` 文件即可使用。

### 2. 移动端访问

- 可以部署到服务器，通过手机浏览器访问
- 支持PWA（渐进式Web应用），可以添加到主屏幕

### 3. 主要操作

#### 记账
1. 点击"收入"或"支出"按钮
2. 填写金额、类别、备注、日期
3. 保存后自动更新余额

#### 旅游规划
1. 允许浏览器获取位置权限
2. 选择旅行模式（穷游/普通游/高端游）
3. 查看目的地列表，绿色高亮表示可以支付
4. 查看详细的费用明细（距离、路费、住宿、餐食）

#### 记事本
1. 点击"新建笔记"
2. 填写标题和内容
3. 点击已有笔记可编辑

## 注意事项

### 定位功能
- 首次使用需要允许浏览器获取位置权限
- HTTPS环境下定位功能更稳定
- 如果定位失败，会使用默认位置（北京）

### 支付记录导入
- 微信/支付宝官方不提供公开API
- 目前需要手动添加记录
- 后续可以通过以下方式实现：
  - 用户手动导出账单CSV文件，然后解析
  - 使用第三方授权服务（需要用户授权）
  - 连接银行API（如果银行支持）

### 旅游费用计算
- 当前使用简化的直线距离计算
- 实际应用中应该使用地图API获取真实路线和价格
- 建议集成高德地图或百度地图API
